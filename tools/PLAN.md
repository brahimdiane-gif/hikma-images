# خطة النشر اليومية — حساب إنستغرام brahime.dian

هذا الملف هو المرجع لمهمتي النشر اليوميتين. عدّله لتغيير الخطة، وستتبعه المهمتان تلقائياً.

## الإعدادات الثابتة

- Metricool: blogId `7614173`، المنطقة الزمنية `Africa/El_Aaiun` (+00:00).
- المستودع: `brahimdiane-gif/hikma-images` (الفرع main). الرابط العام لأي ملف:
  `https://raw.githubusercontent.com/brahimdiane-gif/hikma-images/main/<المسار>`
  (لا تتحقق منه بـ curl؛ الشبكة تمنعه، وMetricool يحمّله بنفسه).
- المولّد: `python3 tools/make.py <post|carousel|story|reel> <json> <out>` (التفاصيل في رأس الملف).
- الخطوط: `GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --sparse https://github.com/google/fonts /home/claude/gfonts && git -C /home/claude/gfonts sparse-checkout set ofl/cairo ofl/amiri`
  (إن رُفض الوصول، استدعِ add_repo للمستودع google/fonts ثم أعد المحاولة).
- الالتزام: `git -c user.name=brahimdiane-gif -c user.email=brahimdiane-gif@users.noreply.github.com commit`، ثم `git pull --rebase` ثم `git push`.
- السجل: `log.md` — اقرأه قبل الاختيار وتجنب أي نص منشور سابقاً، ثم أضف سطراً بالتاريخ والنوع والنص والمصدر في القسم المناسب.

## الدقة (شرط مطلق)

لا تؤلف نصاً ولا تنسبه لغير قائله. تحقق من النص الحرفي والمصدر ببحث ويب قبل الاستخدام. الآيات بنصها وتشكيلها من مصدر موثوق (quran.com أو tanzil.net) مع السورة ورقم الآية. الأحاديث صحيحة فقط مع ذكر المخرّج. الشعر والأمثال بنسبتها الثابتة. إن شككت فاختر نصاً آخر. افتح كل صورة ناتجة بأداة Read وتأكد أن النص مطابق وكامل وغير مقصوص.

## المنشور اليومي — 10:00 صباحاً

| اليوم | الصيغة | المحتوى | theme |
|---|---|---|---|
| الإثنين | post | آية قرآنية | ember |
| الثلاثاء | post | حديث نبوي صحيح | night |
| الأربعاء | reel | حكمة من نهج البلاغة أو أقوال الصحابة | sand |
| الخميس | post | بيت أو بيتان من الشعر العربي الكلاسيكي | ink |
| الجمعة | post | آية قرآنية | olive |
| السبت | carousel | 5 أمثال أو حِكم حول موضوع واحد (الصبر، الصداقة، العلم، الرزق، الأمل…) | sand |
| الأحد | reel | قولة لحكيم أو فيلسوف مترجمة بدقة | night |

- **post**: ملف `images/hikma-YYYY-MM-DD.jpg`. الحقول: title (السطر أو السطران الأقوى)، lines (البقية)، source، theme، seed = رقم يوم السنة. الصورة تحمل تلقائياً عبارة «احفظها لتعود إليها».
- **carousel**: مجلد `images/carousel-YYYY-MM-DD/` (01.jpg …). الحقول: cover (سطران، مثل ["٥ حِكَم", "عن الصبر"])، subtitle، slides (5 عناصر، لكل منها lines و source)، theme، seed. تُضاف شريحة ختامية تلقائياً تطلب من المتابع كتابة رقم الحكمة التي أعجبته. في Metricool ضع روابط كل الشرائح بالترتيب في media، والنوع POST.
- **reel**: ملف `reels/reel-YYYY-MM-DD.mp4` (1080×1920، حوالي 10 ثوانٍ، تظهر الأسطر تباعاً مع صوت خلفية هادئ بلا موسيقى). الحقول: lines (2–4 أسطر قصيرة)، source، theme، seed، quran (true للآيات فقط، فتُكتب بخط أميري). في Metricool: النوع REEL و `"showReelOnFeed": true`. اضغط الصورة أو الفيديو قبل الرفع إن تجاوز 8MB.
- اضغط صور post بجودة 75 (`Image.save(..., quality=75, optimize=True, progressive=True)`).

## نص المنشور (caption)

1. الحكمة (أو أبرز سطر منها)، ثم سطر «— المصدر».
2. سطر فارغ، ثم **سؤال يدعو للتفاعل** متصل بمعنى الحكمة، مثل: «أيّ كلمة فيها لمستك؟»، «من تُهدي هذه الحكمة؟ اذكره في التعليقات»، «هل جرّبت هذا المعنى في حياتك؟». نوّع السؤال كل يوم.
3. سطر قصير يدعو للحفظ أو الإرسال، مثل «احفظها وأرسلها لمن يحتاجها».
4. سطر فارغ ثم **6 إلى 8 وسوم متوسطة الحجم ومتخصصة**، مع وسم ثابت واحد #حكمة_اليوم، وتجنب الوسوم العامة الضخمة وحدها (مثل #اقتباسات #instagram). أمثلة حسب النوع:
   - آيات: #تدبر #آية_وتفسير #القرآن_الكريم #آيات_قرآنية #ذكر_الله
   - أحاديث: #حديث_صحيح #السنة_النبوية #أحاديث_نبوية #هدي_النبي
   - شعر: #شعر_عربي_فصيح #أبيات_شعر #الشعر_العربي #المتنبي (حسب الشاعر)
   - حكم وأمثال: #حكم_عربية #أمثال_عربية #أمثال_شعبية #حكمة_وعبرة
   - فلسفة: #فلسفة #أقوال_الفلاسفة #تأملات

## الستوري اليومية — 6:00 مساءً

آية قرآنية مختلفة عن آية منشور اليوم، `make.py story`، الملف `stories/story-YYYY-MM-DD.jpg`، نوع STORY في Metricool دون حقل text. التناوب: الإثنين night، الثلاثاء olive، الأربعاء ink، الخميس sand، الجمعة ember، السبت night، الأحد olive.

- **ستوري تفاعلية أيام الإثنين والأربعاء والجمعة**: اجعل `autoPublish: false`، فيصل للمستخدم إشعار في تطبيق Metricool ليكمل النشر بنفسه ويضيف ملصقاً تفاعلياً (إنستغرام لا يسمح بإضافة الملصقات عبر النشر الآلي ولا بعد النشر). اقترح عليه في رسالتك ملصقاً محدداً يناسب الآية: استطلاع («هل تحفظ هذه الآية؟ نعم / أحفظها الآن»)، أو سؤال («ما الآية التي تطمئن قلبك؟»)، أو شريط تفاعل.
- باقي الأيام: `autoPublish: true`.

## بعد النشر

أرسل الصورة أو الفيديو للمستخدم بـ SendUserFile (status: proactive) مع سطر يذكر الموعد، ثم نص المنشور بـ SendUserMessage. في أيام الستوري التفاعلية اذكر بوضوح أن عليه فتح إشعار Metricool في الساعة 6 مساءً لإكمال النشر، مع الملصق المقترح. إن فشل أي جزء، أرسل الملف والنص واذكر الخطأ باختصار ليتمكن من النشر يدوياً.
